# Architectural Decision Records

Record decision context and trade-offs here when the [ADR creation criteria](../../.agents/skills/domain-modeling/SKILL.md#offer-adrs-sparingly) apply.

The [repository template](0000-adr-template.md) owns the local ADR format. Name records sequentially: `0001-slug.md`, `0002-slug.md`, and so on. Reserve `0000` for the template.

ADRs preserve decision rationale. Link to the owning contract or invariant for current guarantees. When a later decision supersedes an earlier one, mark the earlier record as superseded and link to its replacement.
